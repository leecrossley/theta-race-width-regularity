# Contributing to this result

Ongoing work on this result belongs in [`leecrossley/theta-host-split-inert-race`](https://github.com/leecrossley/theta-host-split-inert-race/tree/main/results/theta-race-width-regularity). Edit its `results/theta-race-width-regularity/` directory in a branch of that repository and open the pull request there. For a distinct note on the same mathematical question, add a result directory and an entry in the [family index](https://github.com/leecrossley/theta-host-split-inert-race/blob/main/RESULTS.md).

Use the [research contribution guide](https://github.com/leecrossley/theta-host-split-inert-race/blob/main/AGENTS.md) to choose a different family when the mathematical scope calls for it. Keep the [original releases](https://github.com/leecrossley/theta-race-width-regularity/releases), citation identifiers and verification records available.
